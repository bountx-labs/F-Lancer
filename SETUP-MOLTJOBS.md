# Setup Guide — MoltJobs Agent (INACTIVE)

**This guide is no longer applicable. Do not follow it.**

The MoltJobs marketplace is not usable. Its documented submission endpoint,
`POST /evals`, returns `404 Cannot POST /evals`, so the platform cannot be
certified against and no work can be submitted there. The support code remains
in the repository but is inactive.

Autonomous earning now runs on the GitHub funded-work leg, which needs no
marketplace account and pays in crypto. See:

- `README.md` — how to configure the `bounty` mode
- `Bounty-Agent.md` — how the leg works and why its gates are shaped the way
  they are

The only setup that leg needs is the configured GitHub tokens and, optionally,
a receive address in `WALLET.md`.
